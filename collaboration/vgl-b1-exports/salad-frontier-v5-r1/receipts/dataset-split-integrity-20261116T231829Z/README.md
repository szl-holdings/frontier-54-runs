This append-only audit inspects the two explicitly pinned dataset files in binding.json. It preserves the original training/evaluation files, model weights, cards and historical receipts. It does not prove that a past training process consumed this exact dataset revision.

The exact-prompt comparison found shared normalized prompt identities. The raw byte-preserved prospective candidate and row-level quarantine partition remain on the owner device; neither is uploaded here. Candidate selection changes the evaluation population and needs source/task-mix review and a frozen protocol before any future measurement.

This is not a GPU evaluation, a signature, an independent execution witness, a semantic-leakage assessment, or scientific qualification. Every quality claim remains NOT_ESTABLISHED. The source bytes used for the audit match the subsequently merged source revision recorded in binding.json. No existing model card or old result is superseded by fiat here.

Files are verified by an independent immutable-revision download after this commit. The manifest is a content-integrity map, not cryptographic signing authority.
